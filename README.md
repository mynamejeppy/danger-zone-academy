# Danger Zone Academy

A food-safety study game with Food Handler (easy) and Manager (hard) tracks: illustrated study cards, drills, unlockable stations, a practice final exam, XP, badges and side quests.

**Play it:** https://mynamejeppy.github.io/danger-zone-academy/

Progress saves in your browser on each device.

**Install it like an app:** open the link on your phone, then iPhone Safari: Share → Add to Home Screen; Android Chrome: ⋮ → Add to Home screen (or Install app). It opens full screen with its own icon and works offline after the first visit.

Independent study aid. Not affiliated with or endorsed by ServSafe or the National Restaurant Association. Content follows the FDA Food Code; local rules may differ.

## Updating

Edit `danger-zone-academy.html`, then run `sh build.sh` to regenerate `index.html`, commit and push.
